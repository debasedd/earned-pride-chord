# One Line of Earned Pride

[![One Line of Earned Pride](https://make.fun/badge/u-mang-one-line-of-earned-pride-a0138557.svg)](https://make.fun/c/u-mang-one-line-of-earned-pride-a0138557)

A tiny program for [One Line of Earned Pride](https://make.fun/c/u-mang-one-line-of-earned-pride-a0138557) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — a quiet, earned moment of pride for someone in a scene:

> He'd practised the same chord for a year; when it finally rang clean, my father just nodded once, and played it again.

Run it with:

```sh
python3 main.py
```
